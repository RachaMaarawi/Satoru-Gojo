# 🎂 Happy Birthday Selin! 🎁

A custom, interactive web-based birthday gift application featuring personalized themes, mini-games, and a special birthday card modal built with love and code.

## 🌟 About The Project
This project is a unique, fully coded interactive web experience crafted as a birthday surprise for **Selin**. It blends web development with personalized mini-games and dynamic UI elements to create an unforgettable digital celebration.

## 🚀 Features
- **Interactive Mini-Games:** Fun, playable web components built right into the browser experience.
- **Personalized Birthday Card Modal:** A custom greeting card popup featuring tailored wishes and themes.
- **Sleek Front-End Styling:** Smooth animations, custom graphics, and responsive layouts designed for a delightful user experience.
- **Pure Web Technologies:** Built using standard HTML, CSS, and JavaScript—lightweight and ready to run instantly.
